# /link

Cyclops Link lets Prism notice Spark (Claude Code) and Keeper (Codex) working in the same folder, and lets them notice her.
She shares only her coarse state: never prompts, commands, paths or names. It is off until the person turns it on.

## Instructions

Run `prism link $ARGUMENTS` and show its output. Only run `prism link on` or `prism link off` when the person asked for it.
